Approach 2: Shadow DOM + Manual Datastar Apply

This example uses Shadow DOM for style encapsulation. Since Datastar's DOM walker cannot see inside shadow boundaries, we manually call Datastar.apply(shadowRoot) after attaching the shadow content.

How This Works

  1. The web component creates a Shadow DOM with attachShadow({mode: 'open'})
  2. HTML with data-* attributes is placed inside the shadow root
  3. We import Datastar and call Datastar.apply(shadowRoot) to process the shadow content
  4. Signals declared inside the shadow root (localCount) join Datastar's global signal store
  5. The shadow component can read/write signals from outside (globalCount)

Note: Signal scoping is not automatic with this approach. All signals share one global namespace. For true scoped signals, consider the datastar-components plugin or Datastar Pro's Rocket feature.
